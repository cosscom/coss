COSS puts email, and soon SMS, video and scheduling, behind a single API key and a single SDK. You
create an organization, add a project, and call every product with the same key and the same
client:

```ts
import { Coss } from "coss";

const coss = new Coss({ apiKey: process.env.COSS_API_KEY });

await coss.email.send({
  from: "Acme <hello@acme.com>",
  to: "user@example.com",
  subject: "Welcome",
  html: "<p>Hi there</p>",
});
```
