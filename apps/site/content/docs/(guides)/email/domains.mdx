title: Domains
description: Verify a domain to send live email from it.
---

Live keys can only send from domains your organization has verified. Domains belong to the
organization and are shared by all of its projects.

## Adding a domain

Add the domain in the dashboard (**Domains**), then publish the DNS records it shows at your DNS
provider:

| Purpose              | Type    | Name                              | Value                                    |
| -------------------- | ------- | --------------------------------- | ---------------------------------------- |
| DKIM (three records) | `CNAME` | `<token>._domainkey.example.com`  | `<token>.dkim.amazonses.com`             |
| MAIL FROM            | `MX`    | `send.example.com`                | `feedback-smtp.<region>.amazonses.com` (priority 10) |
| MAIL FROM SPF        | `TXT`   | `send.example.com`                | `v=spf1 include:amazonses.com ~all`      |
| DMARC (recommended)  | `TXT`   | `_dmarc.example.com`              | `v=DMARC1; p=none;`                      |

Copy the exact values from the dashboard: the DKIM tokens and region are specific to your domain.

## Verification

COSS checks the records automatically and the dashboard shows the status of each one. Verification
usually takes minutes, but DNS changes can take longer to propagate. If a domain is not verified
within 72 hours, verification fails. Restarting it issues new DKIM records to publish.

When several organizations verify overlapping domains, the most specific one decides who may send:
verifying `mail.example.com` lets you send from `@mail.example.com` even if someone else verified
`example.com`.
