## Send an email

`coss.email.send(params, options?)` sends an email and resolves once the provider has accepted it.
Maps to [`POST /v1/emails`](/docs/api-reference/emails/send-email).

```ts twoslash
import { Coss } from "coss";
const coss = new Coss();
// ---cut---
const { data, error } = await coss.email.send({
  from: "Acme <hello@acme.com>",
  to: "user@example.com",
  subject: "Welcome",
  html: "<p>Thanks for signing up!</p>",
  tags: [{ name: "category", value: "welcome" }],
});

if (data) {
  console.log(data.status, data.sandbox);
  //               ^?
}
```

Fields use the API's snake_case names (`reply_to`, `created_at`). See
[Sending email](/docs/email/sending) for addresses, content, headers and tags.

## Retrieve an email

`coss.email.get(id, options?)` returns an email sent from the same environment as the API key,
with the delivery status of every recipient. Maps to
[`GET /v1/emails/{id}`](/docs/api-reference/emails/get-email).

```ts twoslash
import { Coss } from "coss";
const coss = new Coss();
// ---cut---
const { data: email } = await coss.email.get("email_01k7c8m4q2f3e9v6t5r1n0p8yz");

const bounced = email?.recipients.filter((recipient) => recipient.status === "bounced");
//                                                              ^?
```

## List events

`coss.email.listEvents(id, options?)` returns the email's delivery events, oldest first. Maps to
[`GET /v1/emails/{id}/events`](/docs/api-reference/emails/list-email-events).

```ts twoslash
import { Coss } from "coss";
const coss = new Coss();
// ---cut---
const { data: events } = await coss.email.listEvents("email_01k7c8m4q2f3e9v6t5r1n0p8yz");

for (const event of events?.data ?? []) {
  console.log(event.occurred_at, event.type, event.recipient);
  //                                   ^?
}
```

See [Delivery status](/docs/email/delivery) for what each event means.
