`coss hooks …`: create Hooks applications, event types and endpoints (`endpoints add` prints the signing secret), send messages (`--data`, `-F` fields, or the event type's example), follow deliveries and their attempts, retry one, and open an application's portal. `coss risk …`: assess an event and see the decision, score and reasons (sandbox fixtures produce each decision), list assessments and the review queue, send feedback, and manage the allow and block lists. Help and errors for groups inside groups (`coss hooks apps`) now name their own commands.
