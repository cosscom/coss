First release of `coss-mcp`, the COSS MCP server: coding agents can find emails and diagnose their delivery (`diagnose_email`), send test emails, manage suppressions and domains, inspect webhook deliveries, received emails and logs, and check the account's reputation and billing standing. Run it with `npx -y coss-mcp` and `COSS_API_KEY`.
